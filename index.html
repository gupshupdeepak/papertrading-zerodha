How it works

Open a Kite chart. The panel does the rest.

01

Detect & start

The instrument is filled from the chart (URL, header or title). Press Detect chart price for the entry, choose BUY or SELL and a duration, then Start trade.

02

Countdown

A live clock runs from 5 to 60 minutes (or a custom length). It survives a page reload, and plays a beep and flags the tab title when time is up.

03

Auto-close & journal

At zero it reads the chart price and closes the trade, logging P&L in points and percent. Press Reset to start the next one.

Features

Everything you need to practise timed trades and review them honestly.

🎯

Instrument auto-detect

Reads the symbol from the Kite chart URL, the chart header or the page title — e.g. an options contract like NIFTY26O1922700CE.

📊

Chart-price detection

Finds the price label or OHLC legend, even inside Kite’s embedded chart iframe. Falls back to highlighted text, or a click on the price.

⏱️

Trade timer

5, 15, 25, 30, 45 or 60 minutes, or a custom duration. Resumes after a reload; beeps when finished.

✅

Auto-close at zero

Exit price is captured and the trade closed for you. If it can’t be read, you enter it and click Close trade.

🧾

Journal + CSV export

Recent trades list with BUY/SELL P&L in points and percent. Export to CSV for your spreadsheet or trading diary.

🔒

Paper only, local only

No orders, no API keys, no server. Trades are stored in your Firefox profile.

Good to know

  • Canvas-only charts. If a chart draws its price only on a canvas, no text exists to read. The panel then asks you to click the price or type it.
  • Hovered candle. The chart legend can show the candle under your mouse. Keep the cursor off the chart when the timer ends.
  • Closed page. If the timer ends while the Kite tab is closed, the exit price is not auto-detected (it would be the wrong time). Enter it yourself.
  • Verify prices. Detection reads what is on screen. Check the value before relying on a journal entry.

FAQ

Does it place real orders or connect to my broker? +

No. It is a paper-trading journal only. It never connects to a broker, never asks for credentials or API keys, and has no code path that can place an order.

Which sites does it work on? +

It runs on Zerodha pages (*.zerodha.com), including Kite chart pages such as kite.zerodha.com/markets/ext/chart/.... It does not load on other sites.

How does it detect the instrument and price? +

The instrument comes from the chart URL first, then the chart header and page title. The price comes from the visible price label or OHLC legend in any frame on the page. If neither is readable, highlight a price, click it on the chart when prompted, or type it. The Debug button shows what each frame exposed.

What happens when the timer ends? +

It beeps, reads the chart price and closes the trade automatically. If it can’t read a price, the trade stays open and you enter the exit price and click Close trade.

How is P&L calculated? +

BUY: exit − entry. SELL: entry − exit. Shown in points and as a percent of the entry price. Brokerage, taxes and slippage are not included.

Where is my data stored? Can I export it? +

Only in your Firefox profile (local extension storage). Nothing is sent anywhere. Export CSV gives instrument, side, entry/exit price and time, duration, P&L in points and percent, and status.

How do I install it? +

Download the zip, unzip it, and load it from Firefox’s about:debugging page. Steps are in the Setup Guide.

Setup · ~3 minutes

Install & run your first timed trade

No config files. No API keys. No real orders.

Download and unzip

Download the extension zip and unzip it. You’ll get a folder named kite-paper-trading-timer containing manifest.json.

Load it in Firefox

Type about:debugging in the address bar → This Firefox → Load Temporary Add-on… → select manifest.json.

Firefox removes temporary add-ons when it restarts, so repeat this step after a restart. The extension requests only storage and activeTab, plus access to Zerodha pages.

Open a Kite chart

Open your chart on Kite and reload the tab. The floating Kite Paper Trading Timer panel appears at the top-right. If it’s hidden, click the extension’s toolbar button and choose Show / hide floating panel.

The instrument field fills itself from the chart a couple of seconds after load.

Start a trade

Press Detect chart price next to the entry price, pick BUY or SELL, choose a duration (5, 15, 25, 30, 45, 60 min or custom), and click Start trade.

Tip: verify the detected instrument and price match the chart before you start.

Let it close, then reset

When the clock hits zero the panel beeps, reads the chart price and closes the trade, showing P&L in points and percent. Keep your mouse off the chart at that moment so the legend shows the latest candle.

If the price can’t be read, type the exit price and click Close trade. Press Reset to clear the panel for the next trade.

Review your journal

Recent trades lists every paper trade. Export CSV saves them as paper-trades.csv. Clear history wipes the saved list.

Troubleshooting

  • Panel doesn’t appear? Reload the Kite tab after loading the extension, or use the toolbar button to show it.
  • Instrument or price not detected? Click Debug and note which frames responded and what candidates they found. Then type the value manually or send the output via the contact page.
  • Wrong exit price? The legend may have shown a hovered candle. Move the mouse off the chart and use Detect chart price again.
  • Timer ended while the tab was closed? The trade stays open and asks for a manual exit price so the journal stays honest.
  • Extension gone after restarting Firefox? Temporary add-ons are removed on restart. Load it again from about:debugging.
